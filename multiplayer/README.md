# Онлайн-партии

Worker с Durable Object хранит комнаты, проверяет правила и время; статический сайт остаётся на GitHub Pages. Первая версия рассчитана на двух игроков по ссылке и контроль 5+0; общий рейтинг не меняется. Идентификатор комнаты случайный, ссылка является приглашением: не публикуйте её. Место игрока привязано к локальному хранилищу браузера; его очистка или другой браузер не восстановят доступ к занятому месту.

## Публикация

Нужен аккаунт Cloudflare с доступом к Workers и Durable Objects. В корне репозитория выполните `npx wrangler login`, затем `npx wrangler deploy --config multiplayer/wrangler.toml`. После публикации скопируйте HTTPS-адрес Worker в `ONLINE_SERVER` файла `app/js/online-config.js` (без завершающего слэша), затем опубликуйте изменение сайта через обычный pull request и GitHub Pages. Не записывайте токены и ключи в репозиторий. До настройки адреса экран сообщает, что сервер ещё не опубликован.

Учтите лимиты и стоимость выбранного тарифа Cloudflare. Worker и комнаты доступны только пока сервис развёрнут и доступен. Время на сервере продолжает идти при разрыве соединения. Чтобы проверить: создайте партию, откройте приглашение в другом браузере или на другом устройстве, сделайте ходы с обеих сторон, переподключитесь и завершите партию. Защищайте ссылку: любой, кто получил её до второго игрока, может занять свободное место.

## Локальная проверка

Из корня: `npx wrangler dev --config multiplayer/wrangler.toml --local`. Для запуска сайта отдельно используйте `python3 -m http.server 8000 --directory app`. Временно укажите `http://127.0.0.1:8787` в `ONLINE_SERVER` для локальной проверки, затем верните или замените адрес перед публикацией. Используйте отдельные профили браузера, чтобы имитировать двух игроков. Не используйте локальный адрес в опубликованной версии.
