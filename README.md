# Шахматы — разбор партий на Stockfish

Мобильное веб-приложение (PWA): игра против Stockfish 18 и разбор партий с оценкой каждого хода.
Работает прямо на телефоне, без сервера и без сборки. После первого открытия работает и без интернета.

**Открыть:** https://slave28781.github.io/chess/

## Что умеет

- **Игра против Stockfish** — 8 уровней: от «Новичка» до полной силы. Есть подсказка, отмена хода и выбор цвета.
- **Разбор партии** — вставьте PGN из chess.com, lichess или своей игры. Каждый ход получит оценку:

  | Значок | Оценка | Когда ставится |
  |---|---|---|
  | !! | Бриллиантовый | лучший ход с жертвой фигуры (не пешки) |
  | ! | Отличный | единственный хороший ход: второй по силе хуже на ≥ 20 % шансов |
  | ★ | Лучший | совпал с первым выбором Stockfish |
  | 👍 | Очень хороший | потеря шансов < 2 % |
  | ✓ | Хороший | потеря < 5 % |
  | 📖 | Теория | ход из дебютной книги |
  | ?! | Неточность | потеря < 10 % |
  | ? | Ошибка | потеря < 20 % |
  | ✗ | Упущение | ответная ошибка после ошибки соперника |
  | ?? | Зевок | потеря ≥ 20 % |

  «Шансы» — вероятность победы по оценке движка (формула lichess). Точность игрока — среднее точностей его ходов.
- **Комментарии к ходам** — по фактам из анализа: «Зевок! Теряется ферзь: Кxh4. Нужно было Кf6», «Был мат в 3 хода: …».
- **Свои заметки** к любому ходу и экспорт в PGN с комментариями и оценками.
- **Свои варианты** — сделайте ход на доске во время разбора, и движок оценит его сразу.
- **Задачи из ваших ошибок** — каждая ваша ошибка становится задачей «найди ход лучше». Любой ход, не уступающий лучшему, засчитывается.
- **Свободный анализ** — доска с живой оценкой, можно начать с любой позиции (FEN).
- Русская (Кf3) или английская (Nf3) запись ходов, 4 темы доски, звуки.

## Как поставить на телефон

- **iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Установить приложение».

Партии, разборы и заметки хранятся только на телефоне (localStorage). Если очистить данные браузера, они пропадут.

## Устройство

```
app/                 — сайт (публикуется на GitHub Pages как есть)
  js/chess.js        — правила: ходы, FEN, SAN, мат/пат/ничьи, размены (SEE)
  js/pgn.js          — чтение и запись PGN, русская нотация
  js/engine.js       — Stockfish по UCI: очередь задач, уровни игры
  js/review.js       — шансы на победу, точность, оценка силы хода
  js/comments.js     — автокомментарии
  js/openings.js     — дебютная книга (~120 линий)
  js/board.js        — доска: анимация, тап и перетаскивание, стрелки
  js/screens/*.js    — экраны: Игра, Анализ, Задачи, Партии
  engine/            — Stockfish 18 lite (WebAssembly, один поток)
tests/               — тесты (node --test)
```

## Тесты

```
npm test        # то же: node --test tests/*.test.js
```

- `perft.test.js` — генерация ходов сверяется с эталонными числами perft (6 позиций, в том числе 119 060 324 из начальной позиции на глубину 6).
- `chess.test.js` — FEN, SAN, PGN (включая формат chess.com и русскую нотацию), конец партии, размены.
- `review.test.js` — оценка ходов на подставных оценках: зевки, жертвы, «единственный ход», упущения, комментарии.
- `engine.test.js` — настоящий Stockfish 18 (та же сборка, что в браузере): «Партия в опере», ловушка Легаля, детский мат.

GitHub Actions прогоняет тесты на каждый PR и при пуше в `main` публикует `app/` на GitHub Pages.
